Phase 5 — Pickup & Return Management 10 APIs
GET ADMIN ONLY
/api/admin/pickups
Admin list pickup schedule with status filters.
curl -X GET "http://localhost:5000/api/admin/pickups?status=READY" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/pickups/code/:code
Admin search pickup by QR/Barcode code.
curl -X GET "http://localhost:5000/api/admin/pickups/code/RNT-PICKUP-XXXXXX" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
POST ADMIN ONLY
/api/admin/pickups/:id/confirm
Admin confirm pickup & transition Order=ACTIVE.
curl -X POST "http://localhost:5000/api/admin/pickups/<PICKUP_ID>/confirm" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"notes": "Verified customer ID proof"}'
POST ADMIN ONLY
/api/admin/returns/:id/inspect
Admin perform return inspection & record damages.
curl -X POST "http://localhost:5000/api/admin/returns/<RETURN_ID>/inspect" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"condition": "DAMAGED", "damage_report": "Scratched lens"}'
POST ADMIN ONLY
/api/admin/returns/:id/confirm
Admin confirm return & detect ON_TIME vs LATE.
curl -X POST "http://localhost:5000/api/admin/returns/<RETURN_ID>/confirm" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"actual_return_at": "2026-09-04T18:00:00Z"}'
Phase 6 — Late Fee Management 10 APIs
POST ADMIN ONLY
/api/admin/late-fee-configs
Admin create late fee configuration rule.
curl -X POST "http://localhost:5000/api/admin/late-fee-configs" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name": "Daily Rule", "charging_unit": "DAILY", "rate": 500, "grace_period": 2, "max_fee": 5000}'
POST ADMIN ONLY
/api/admin/returns/:returnId/calculate-late-fee
Calculate late fee & perform security deposit settlement.
curl -X POST "http://localhost:5000/api/admin/returns/<RETURN_ID>/calculate-late-fee" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/late-fees/outstanding
View all outstanding penalties > 0.
curl -X GET "http://localhost:5000/api/admin/late-fees/outstanding" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
POST ADMIN ONLY
/api/admin/late-fees/:id/waive
Admin waive late fee & trigger full deposit refund.
curl -X POST "http://localhost:5000/api/admin/late-fees/<LATE_FEE_ID>/waive" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"notes": "Waived due to customer emergency"}'
GET CUSTOMER
/api/orders/:orderId/late-fee
Customer view own order late fee and settlement status.
curl -X GET "http://localhost:5000/api/orders/<ORDER_ID>/late-fee" \
  -H "Authorization: Bearer <CUSTOMER_TOKEN>"
Phase 7 — Rental Operations Dashboard 12 APIs
GET ADMIN ONLY
/api/admin/dashboard/overview
Main dashboard overview metrics in single payload.
curl -X GET "http://localhost:5000/api/admin/dashboard/overview" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/dashboard/active-rentals
List all currently active & picked up rentals.
curl -X GET "http://localhost:5000/api/admin/dashboard/active-rentals" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/dashboard/due-today
List rentals whose return date is today.
curl -X GET "http://localhost:5000/api/admin/dashboard/due-today" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/dashboard/upcoming-pickups
List upcoming pickups for N days (default 7).
curl -X GET "http://localhost:5000/api/admin/dashboard/upcoming-pickups?days=7" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/dashboard/revenue
Calculate total rental revenue within date range.
curl -X GET "http://localhost:5000/api/admin/dashboard/revenue?from=2026-08-01&to=2026-08-31" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/dashboard/priorities
Get prioritized operational alerts needing admin action.
curl -X GET "http://localhost:5000/api/admin/dashboard/priorities" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
GET ADMIN ONLY
/api/admin/dashboard/revenue-summary
Get revenue breakdown grouped by daily, weekly, or monthly.
curl -X GET "http://localhost:5000/api/admin/dashboard/revenue-summary?period=monthly" \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
